# Silence is not disagreement — an unmentioned feature is a question, not a contradiction

**Silence is not disagreement. A source that says nothing about X has not ruled
against X.**

Two documents that describe the same thing differently disagree, and the one
with authority wins. A document that describes something the other **never
mentions** is a different situation entirely, and it has exactly one correct
handling: **raise it, and leave the text intact until someone with standing
rules.**

**How the confusion happens.** Reconciling A against B, you build a mental model
of B and start treating it as complete. Anything in A that is not in that model
reads as *contradicted* rather than *unaddressed* — and deleting it feels like
finishing the job rather than making a decision.

**What it costs when it goes wrong.** The feature does not merely vanish; it
vanishes **with a note explaining why it was right to remove it**. That note is
worse than the deletion, because the next reader finds a settled question and no
reason to reopen it. A silently dropped line invites someone to notice. A
confidently corrected one does not.

**The habit that prevents it.** When reconciling, sort every difference into two
piles before writing anything: *both describe this, differently* and *only one
describes this at all*. The first pile is work. **The second pile is a list of
questions, and it goes to the owner whole.**

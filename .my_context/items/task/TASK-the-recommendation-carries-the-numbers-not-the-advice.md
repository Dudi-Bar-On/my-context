# the recommendation carries the numbers, not the advice

"Raise the budget" is not actionable. The disclosure says what the pinned tier COSTS, what it is SET to, and what it would have to BE -- and offers a small set of concrete values plus free entry, per the owner's requirement.

THE RECOMMENDED VALUES SHOULD BE DERIVED, not invented: the exact cost, that cost with headroom for the corpus to grow by a stated fraction, and the largest value that still leaves the other three tiers and a working reserve inside the window. Each labelled with what it buys and what it costs, because a list of numbers with no consequences attached is a guess with a dropdown.

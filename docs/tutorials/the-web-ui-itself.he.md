# לפתוח את ממשק הרשת ולהשתמש בו

**נבדק על:** my_context v1.0.2, ‏Node 24, ‏Windows 11.

הערה על הכותרות: ארבע הכותרות הנדרשות מופיעות כאן באנגלית לצד העברית, מפני שבדיקת
הקיום של המוצר מחפשת בדיוק את המחרוזות האנגליות. הטקסט עצמו מתורגם, לא מסוכם.

## What it is for — למה זה נועד

יש שאלות שלא נכנסות לטרמינל. "אילו חלקים במאגר הקוד הזה המאגר שלי באמת מכסה?" היא
מפה. "מה תקציב pinned קטן יותר היה מפסיק לספק?" היא מחוון. "למה הפריט הזה הגיע וזה
לא?" היא שלוש תשובות זו לצד זו.

ממשק הרשת הוא המשטח לשאלות האלה. הוא אינו מוצר שני: כל עובדה שהוא מצייר נקראת מאותו
מאגר שהשורה קוראת, וכל מסך נוקב בנקודת הקצה שמאחוריו.

## How it works — איך זה עובד

‏`mycontext ui` מפעיל שרת HTTP ש**נקשר ל‑`127.0.0.1` בלבד** ומסרב לעלות על כל
מארח אחר. הוא יוצא מעצמו אחרי שמונה שעות ללא בקשת `/api` שאינה זרם, כך שלשונית
רקע שנשכחה אינה מחזיקה אותו; ‏`--idle-ms` מזיז את החלון הזה, עד תקרה של 24 שעות.

הפורט הוא הפורט הזמני שמערכת ההפעלה מקצה, אלא אם `ui.port` ב‑`.my_context/config.json`
או `--port` נוקבים באחד.

**עשרים מסכים, בארבע קבוצות ברשימת הניווט**, ושמות הקבוצות הם הטענות של המוצר
עצמו על מה כל מסך נועד לו:

- **הזרקה — מה מגיע**: תצוגת הזרקה, כיסוי היקף, סימולטור תקציב, מוזרק כעת.
- **ראיות — למה כן או לא**: זרם ביקורת, שאילתה, אבחון, דעיכה, קשרים, מצב.
- **שינוי — מורכב, לא מורץ**: תור סקירה, תיעוד, מרכיב פקודות, הגדרות, נהלים,
  ייצוא / ייבוא, חבילות תבנית.
- **קריאה**: תיעוד, מדריכים, לימוד.

**"מורכב, לא מורץ" הוא הכלל, והאישור הוא החריג לו.** רוב המסכים בעלי אופי הכתיבה
מסתיימים בשורת shell שאתה מעתיק. במקומות שבהם הממשק כן מריץ פקודה, הוא מריץ אחת
מ‑27 כניסות הקטלוג — 19 כתיבות ו‑8 קריאות — ועושה זאת דרך מנגנון שנבנה סביב תכונה
אחת: *המחרוזת שאדם קרא בדיאלוג האישור וה‑argv שרץ הם אותו הדבר*. הדפדפן שולח מזהה
קטלוג ואוסף ערכים, לעולם לא פקודה; השרת בונה את ה‑argv מחדש מאותו קובץ שהדפדפן
הרכיב ממנו; nonce קושר את ההרצה ל‑argv שהשרת בנה; וכל הרצה נרשמת ביומן הביקורת
לפני שהיא מתחילה ושוב כשהיא מסתיימת. שש‑עשרה מתוך ה‑27 יושבות על גבול האמון
ומקבלות את האישור המפורט שדה־שדה ולא את הקל.

## From the CLI — מהשורה

```bash
mycontext ui                     # הפעל ופתח דפדפן
mycontext ui --no-open           # הפעל והדפס את הכתובת
mycontext ui --port 4321         # פורט קבוע
mycontext ui --idle-ms 600000    # צא אחרי עשר דקות סרק
mycontext ui --nonce             # בקש אישור משרת שכבר רץ
```

‏`--nonce` הוא זה שראוי להסבר. הוא אינו מפעיל דבר: הוא מבקש משרת שכבר רץ להנפיק
אישור חד‑פעמי, לולאתי בלבד, ופותח את הדפדפן בכתובת
`http://127.0.0.1:<port>/#<nonce>`. עם `--no-open` הוא מדפיס במקום זאת קישור בעל
חיים ארוכים יותר. כל הנפקה נרשמת ביומן הביקורת.

כשאין רישום של שרת רץ, הפקודה אומרת בדיוק את זה — שאין רישום, ושייתכן בהחלט ששרת
מאזין בכל זאת — במקום לטעון שאין שרת. "אין רישום" אינה מדידה, והפקודה הזו אינה
מדווחת עליה כאילו הייתה.

**פקודת ה‑slash.** ‏`/mycontext:ui` מפעילה את הממשק מתוך סשן.

**מה שהשורה יודעת לעשות כאן והממשק לא.** להפעיל, לעצור ולכתובת את השרת; לבחור את
הפורט ואת חלון הסרק; וכל שאר הדברים במוצר הזה, מפני שמשטח הכתיבה של הדפדפן הוא
27 כניסות קטלוג ולשורה יש 43 פעלים.

## From the UI — מהממשק

ברגע שהוא פתוח, הממשק עצמו הוא מה ש‑23 המדריכים האחרים עוסקים בו — כל אחד מהם
נוקב במסך שדרכו מגיעים ליכולת שלו.

שתי נוחויות שייכות לממשק כולו ולא למסך מסוים:

- **הוא דו‑לשוני.** המחרוזות של כל מסך מגיעות מטבלה, באנגלית ובעברית, ושתיהן
  מוחזקות שוות על ידי בדיקת התאמה ולא על ידי משמעת.
- **הוא לעולם אינו נסוג לשפה אחרת.** במקום שבו תרגום או מסמך אינם קיימים, המסך
  אומר זאת כמצב מדוד; הוא אינו מגיש לך בשקט את הגרסה האנגלית תחת תווית עברית.

**מה שהממשק יודע לעשות כאן והשורה לא.** לצייר. עץ הכיסוי, גרף הקשרים, מדרגות
התקציב ורצועת החום של הדעיכה אינם תשובות טרמינל שרונדרו בדפדפן — הם תשובות
שטרמינל אינו יכול לתת כלל.

**מה שהממשק אינו יכול לעשות כאן.** להגיע לשום דבר מחוץ למכונה הזו (הוא נקשר
ללולאה המקומית ומסרב כל מארח אחר); להריץ פקודה שאינה אחת מ‑27 כניסות הקטלוג; או
להריץ אחת מהן בלי אישור שקראת קודם.

# למצוא את מה שהפסיק להיות חשוב

כל פקודה וכל בלוק פלט בעמוד הזה הורצו מול סביבת עבודה נקייה בזמן הכתיבה. אין כאן
שום דבר להמחשה בלבד.

**נבדק על:** my_context v1.0.2, ‏Node 24, ‏Windows 11.

הערה על הכותרות: ארבע הכותרות הנדרשות מופיעות כאן באנגלית לצד העברית, מפני שבדיקת
הקיום של המוצר מחפשת בדיוק את המחרוזות האנגליות. הטקסט עצמו מתורגם, לא מסוכם.

## What it is for — למה זה נועד

מאגר שרק גדל מפסיק להיקרא. איפשהו בתוכו יש פריטים שאיש לא נזקק להם חודשים —
ואיפשהו אחר יש פריטים שנראים נטושים ופשוט מכסים תיקייה שאיש לא נגע בה ברבעון הזה.

דעיכה היא הדוח שמבחין בין השניים, והוא זהיר במיוחד באמירה מה מהם הוא כלל אינו
יכול להבחין ביניהם.

## How it works — איך זה עובד

**"קר" פירושו: לא הוזרק אוטומטית ב‑N הסשנים האחרונים.** החלון נספר ב*סשנים*, לא
בשבועות — אין שעון במדידה הזו.

**הרשומות רושמות הזרקה, לא קריאה ולא הישענות.** זו ההסתייגות שהדוח פותח בה, וזו
כל הסיבה שהיכולת הזו היא דוח ולא פעולה. פריט חדש, פריט שנועצו בו עם
`mycontext show`, פריט שנקרא דרך כלי ה‑MCP‏ `get_item`, ופריט שנפתח כקובץ Markdown
— כולם נראים כאן בדיוק כמו פריט נטוש.

**הרשומות שומרות שורה אחת לכל סשן, פריט ושכבה.** חזרה בתוך סשן אחד מתנגשת, ולכן
מה שנשמר הוא הזרקות ראשונות בלבד.

שלוש צורות שכדאי להבחין ביניהן, והדוח עושה זאת:

- **קר** — לא הוזרק בחלון.
- **מעולם לא הוזרק** — סוג, לא מספר גדול. אין לו היסטוריה כלל, וזה שונה מהיסטוריה
  שנפסקה.
- **מוצמד וקר** — סימן לפגם, לא דעיכה. פריט `always: true` שאינו מגיע הוא באג
  בבחירה.

**פריטים בלתי מוגבלים הם תצוגה, לא סל.** פריטים פעילים, נורמטיביים וחסרי היקף
מופיעים כתצוגת רוחב משלהם מעל הקרים והחמים יחד — כל אחד נספר *גם* כאחד מהשניים. זו
אינה קטגוריה רביעית, וזה אינו פגם: הוסף glob של היקף רק אם התכוונת לצמצם את המקום
שבו הפריט חל.

## From the CLI — מהשורה

```console
$ mycontext decay
my_context decay — items not injected in the last 20 session(s). The ledger holds 0 session(s).
  "cold" means: not auto-injected in the last window of sessions. It does NOT mean unused — the
  ledger records injection, not reading or reliance, so a new item, and any item consulted via
  `show`, MCP `get_item`, or the Markdown file directly, look exactly like an abandoned one here.
  Do not supersede or deprecate anything on this report alone — verify real usage first.
  (no sessions recorded yet — nothing here has been measured; "cold" currently means only "never
  injected")

cold (2) — not auto-injected in the window; check before acting:
  ┌───────────────────────────────────────────────┬────────────┬────────────────┐
  │ id                                            │ type       │ usage          │
  ├───────────────────────────────────────────────┼────────────┼────────────────┤
  │ CONST-card-numbers-never-reach-the-logs       │ constraint │ never injected │
  │ RULE-every-price-is-an-integer-of-minor-units │ rule       │ never injected │
  └───────────────────────────────────────────────┴────────────┴────────────────┘

unrestricted (1) — active and normative with no scope, so they apply to every file and compete for
the jit budget on every file operation. Each is also counted as cold or warm — this is a view over
those rows, not a fourth bucket. Not a defect: add a scope glob only if you meant to narrow where
the item applies.
  ┌───────────────────────────────────────────────┬──────┬────────────────┐
  │ id                                            │ type │ usage          │
  ├───────────────────────────────────────────────┼──────┼────────────────┤
  │ RULE-every-price-is-an-integer-of-minor-units │ rule │ never injected │
  └───────────────────────────────────────────────┴──────┴────────────────┘
```

קרא את ההסתייגות לפני הטבלה. על רשומות צעירות הדוח אומר זאת ישירות: *"cold"
currently means only "never injected"*.

```bash
mycontext decay --sessions 50    # חלון אחר
mycontext decay --all            # כולל מה שתצוגת ברירת המחדל מסתירה
mycontext decay --json           # אותה תשובה, קריאה למכונה
```

פעולה על ממצא דעיכה היא עריכת מאגר רגילה — ‏`mycontext supersede <old> --by
<new>`, או `mycontext edit <id> --status deprecated`. אין פקודת "ניקוי", בכוונה.

**פקודת ה‑slash.** ‏`/mycontext:decay`.

**מתוך סוכן**, ‏`decay_report` עונה על אותה שאלה.

**מה שהשורה יודעת לעשות כאן והממשק לא.** לשנות את החלון, לבקש את הרשימה המלאה,
ולקחת את התשובה כ‑JSON. וגם לפעול לפיה: לא supersede ולא deprecate נגישים ממסך
הדעיכה.

## From the UI — מהממשק

מסך **דעיכה** (‏`nav.ev`) הוא *תרשים, לא טבלה — של סשנים*, והוא מצייר שתי מדידות
שונות שקל להתבלבל ביניהן:

- **מסרק העדכניות** — שן אחת לכל פריט, לעולם לא מקובץ לסלים, כך שמאגר של ארבעים
  פריטים הוא ארבעים שיניים ולא חמישה עמודים. חם, קר, מעולם לא הוזרק, ומוצמד וקר —
  לכל אחד סימן משלו.
- **רצועת חום של מסירה ל‑90 יום**, לכל פריט, תא אחד ליום. העוצמה היא כמה נמסר;
  **מקווקו** פירושו *נשפך* באותו יום; ריק פירושו ששום דבר לא קרה — שקט, ולא בחירה
  או השלכה.

ההסתייגות נמצאת על המסך, ולא רק בטרמינל: הציר והתג נספרים שניהם בסשנים, והמסך
מצהיר אם החלון יושב בתוך מה שהרשומות באמת יכולות לראות או חורג ממנו — ובמקרה הזה
"קר" פירושו בעיקר "חדש", והוא אומר זאת.

**מה שהממשק יודע לעשות כאן והשורה לא.** להראות *מתי* המסירה נפסקה ולא רק שהיא
נפסקה, ולהראות ימים שנשפכו לצד ימים שנמסרו — לדוח בטרמינל אין ציר זמן כלל.

**מה שהממשק אינו יכול לעשות כאן.** לשנות את החלון, או לפרוש משהו. דעיכה היא קריאה
בשני המשטחים; רק הטרמינל יכול לפעול לפי מה שהיא מוצאת.

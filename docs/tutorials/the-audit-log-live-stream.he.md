# לצפות במה ש-my_context עושה, בזמן אמת

כל פקודה וכל בלוק פלט בעמוד הזה הורצו מול סביבת עבודה נקייה בזמן הכתיבה. אין כאן
שום דבר להמחשה בלבד.

**נבדק על:** my_context v1.0.2, <span dir="ltr">Node 24, Windows 11</span>.

הערה על הכותרות: ארבע הכותרות הנדרשות מופיעות כאן באנגלית לצד העברית, מפני שבדיקת
הקיום של המוצר מחפשת בדיוק את המחרוזות האנגליות. הטקסט עצמו מתורגם, לא מסוכם.

## What it is for — למה זה נועד

שתי שאלות שהמוצר הזה מסרב לענות עליהן מהזיכרון: *אדם החליט את זה, או סוכן?*
ו*מה התקציב באמת הפיל?*

יומן הביקורת עונה על שתיהן, מפני שהוא המקום היחיד שבו שפיכה נרשמת בכלל. כל דבר
שמשנה או מזריק נוסף אליו.

## How it works — איך זה עובד

**זהו יומן לכתיבה בלבד על הדיסק**, תחת `.my_context/.audit/`, וההיטל של SQLite
מעליו הוא בר-השלכה. מחיקת בסיס הנתונים אינה מאבדת דבר;
`mycontext audit replay-ledger` משלים את ההיטל בהדרגה ובונה אותו מחדש במלואו רק
אם היומן התפצל.

**שבעה סוגי רשומות**: שינויים, הזרקות, פעולות הוק, שינויי מיקוד, סירובי גישה,
צעדי התקדמות, והרצות פקודה — כשהאחרון הוא צמד `execute` / `execute-done` שמרכיב
הפקודות של הדפדפן כותב סביב הרצה מאושרת.

**שני צירים שכדאי ללמוד:**

- **<span dir="ltr">`--origin`</span>** הוא ציר גבול האמון: <span dir="ltr">`human`, `agent`, `ingest`</span>. זו התשובה
  המהירה ביותר ל"אדם החליט את זה?" (כלי ה-MCP קורא לאותו פרמטר `actor`.)
- **<span dir="ltr">`--role`</span>**, שיש לו משמעות רק יחד עם `--items`, בוחר אם לספור פריט כ-`subject`
  של הרשומה, כ-`injected` או כ-`spilled`. העברה שלו בלי `--items` נדחית ולא
  מתעלמים ממנה.

**היסטוריה מיובאת נשמרת בנפרד.** רשומות שהגיעו עם ייצוא של מישהו אחר נוחתות
ב-`.audit/imported/`, כך שקורא תמיד יכול להבחין בין נצפה ובין נמסר בעל פה.

**שינוי מיקוד הוא שינוי משטר, לא שורה.** כל מה שאחריו בזרם נבחר לפי כללים אחרים,
ושני המשטחים מתייחסים לזה כך.

## From the CLI — מהשורה

```console
$ mycontext audit --summary
my_context: 3 audit record(s) in range, by operation:
  ┌────────┬───────┬────────────────┐
  │ op     │ count │ last           │
  ├────────┼───────┼────────────────┤
  │ create │ 3     │ 09-05 11:20:28 │
  └────────┴───────┴────────────────┘
```

```bash
mycontext audit                              # רשומות אחרונות
mycontext audit --since 1d --origin agent    # מה Claude עשה היום
mycontext audit --items --role injected      # אילו פריטים באמת מגיעים לסשנים
mycontext audit --items --role spilled       # אילו פריטים התקציבים מפילים
mycontext audit --item <id>                  # ההיסטוריה של פריט אחד
mycontext audit --op create --limit 50       # פעולה אחת
mycontext audit --files                      # מגולגל לפי קובץ
mycontext audit replay-ledger                # בנה מחדש את היטל השימוש
```

**פקודת ה-slash.** <span dir="ltr">`/mycontext:audit`</span>.

**מתוך סוכן**, `audit_log` קורא את אותו יומן; פרמטר הסינון שלו הוא `actor`,
במקום שבו השורה אומרת `--origin`.

**מה שהשורה יודעת לעשות כאן והממשק לא.** כל מסנן שלמעלה כדגל בר-הרכבה, <span dir="ltr">`--files`,
`--json`</span>, ו-`replay-ledger`. בנייה מחדש של ההיטל בפרט היא מעשה טרמינל שאין לו
מקבילה בדפדפן.

## From the UI — מהממשק

מסך **זרם הביקורת** (`nav.ev`) מנסח את הסיבה שלו עצמו לקיום: *הרישום היחיד של מה
שנשפך*.

הוא מצייר את הזרם בזמן אמת, בחמש עמודות — **מתי**, **סוג**, **פעולה**, **מי /
נושא** ו**פרטים** — עם מסנן לכל סוג רשומה, ובנוסף:

- **דופק פעילות**, עמודה אחת לכל עשר שניות, החדשה ביותר בקצה הקריאה. הגובה הוא
  מספר הרשומות באותה עמודה; הצבע הוא הסוג.
- **שתי שתיקות שונות, נקובות בשם.** *"נמדד, וריק — שום רשומה לא נחתה ב-N הדקות
  האחרונות"* אינו אותו דבר כמו *"לא נמדד — מעולם לא נבנה היטל ביקורת לסביבת העבודה
  הזו"*, והמסך מסרב לצייר אותן זהות.
- **קיבוץ מסלולים.** שיגור תת-סוכן, הצעדים שלו והעצירה שלו מצורפים לפי מזהה הסוכן
  ומקופלים לשורה אחת, ניתנת לפתיחה, עם בקרות לבודד מסלול יחיד או לנקות את המסנן.
- **כלל שינוי המשטר.** שינוי מיקוד מצויר כקו לרוחב הזרם ולא כשורה בתוכו, כך שהוא
  נראה כגבול שהוא באמת.

**מה שהממשק יודע לעשות כאן והשורה לא.** לצפות בזה קורה. הדופק, קיפול המסלולים וקו
המשטר הם כולם צורות על פני זמן שרשימת טרמינל מדופדפת אינה יכולה להראות, והזרם
מתעדכן כשרשומות נוחתות.

**מה שהממשק אינו יכול לעשות כאן.** לסנן לפי מקור, פריט או פעולה כדגלים
בני-הרכבה, לגלגל לפי קובץ, לייצא את הזרם, או לבנות מחדש את ההיטל. זו תצוגה חיה
מעל יומן שהוא לעולם אינו כותב אליו.

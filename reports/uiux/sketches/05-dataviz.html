what governsמה חל על

Degradation, four layers, each disclosed. (1) The wire carries directories, not files — one row per directory with rolled-up counts; per-file detail is fetched for the opened directory only. (2) The match loop is inverted: injection() is path-independent and runs once per item; unscoped-injectable items match every path with zero matchesScope calls; only scoped items are tested per path, and a directory whose subtree cannot prefix-match any glob is decided once for the whole subtree. (3) Two distinct truncations, never merged into one word: the walk's own FILE_LIMIT = 20_000 bound, and the coverage computation's time budget. (4) Only the visible ~40 rows are in the DOM.

2Injection preview — the budget ribbonתצוגת הזרקה

One picture, three answers. Above the line: what fit, each segment sized by its real itemCost. Below: what did not, at the width it would have taken. The selector is first-fit, not priority truncation — it skips an over-budget item and keeps going — so a wide ghost followed by a narrow fill is the algorithm being honest. A design that drew spills as a tail would misrepresent it.

Widths come from /api/simulate, not /api/select. /api/select is the parity endpoint and returns select()'s serialization and nothing else; /api/simulate returns costs: {id, tokens}[] for every id in full ∪ spilled, each the exported itemCost. The screen composes the two rather than re-deriving a cost from the spill's reason string.

3Budget simulator — the admission staircaseסימולטור תקציב

Dragging a budget is a search unless you can see where the thresholds are. The staircase is the selector's own answer at every breakpoint, computed once as a sweep and scrubbed with no further requests. The downward steps are the point: because admission is first-fit, raising a budget can admit one large item and evict two smaller ones. A simulator that assumed monotonicity would draw a lie.

4Decay — the recency combדעיכה

"This rule has not been injected in six weeks" is a position on an axis, and "never injected" is not a large number on that axis — it is a different kind, so it gets its own terminal bucket. Time comes from MAX(injected_at); cold/warm membership comes from computeDecay, whose window is counted in sessions. Two different measurements, so two different encodings, and the caveat rides with the chart.

warm — injected inside the window cold never injected pinned and cold — a defect signal, not decay
Two traps the source documents by name. DecayReport.unrestricted is a breadth view over cold ∪ warm, not a third bucket — a stacked bar of the three double-counts, and its own doc comment says so. It is drawn here as a ∀ marker on the rows it applies to. And a always:true item that is cold cannot be decay: it is injected at every session start unless it spilled. That is why DecayRow carries always at all.

90-day heatstrip — delivered vs spilled, per itemרצועת חום

One cell per day, from the audit projection: audit_item joined to audit.at, both indexed. Solid = delivered, hatched = spilled. A six-week gap is six weeks of empty cells and needs no reading. The ledger alone cannot draw the hatched cells — it records deliveries only.

5Relation ego-graph — columns, not a hairballגרף יחסים

Five deterministic columns: radius-2 in · radius-1 in · focus · radius-1 out · radius-2 out. Relations in this vocabulary are directional, so direction is the layout and no simulation is needed. Edges only ever join adjacent columns, so the crossing count is bounded by construction. O(n), stable, 60-node cap with the overflow shown in the column it was cut from.

focus target not in corpus superseded load-bearing referential dangling
The nodes carry ids, never titles — and that is a bidi decision, not a space one. An id is grammar-guaranteed ASCII (uppercase prefix, hyphen, lowercase body), so it is LTR-safe by construction. A title is free text and may be Hebrew, which inside an SVG needs per-<text> bidi control that CSS cannot supply from outside. Putting titles in the HTML detail pane — which mirrors for free — removes SVG bidi from the problem entirely. isLoadBearing already classifies the vocabulary, so a dangling relates_to reads as noise and a dangling constrains reads as an alarm, which is the true difference.

6Live audit stream — pulse, feed, regimeזרם ביקורת

Three of the four record kinds are events in a list. The fourth is not: a focus change touches no item and injects nothing, but it changes what every later selection delivers. Drawn as a row it is trivia; drawn as a rule across the feed it says everything below this line was selected from a different corpus — which is precisely the disappearance the focus records exist to explain.

injection mutation (human) mutation (agent) hook — injected nothing focus — a regime boundary
Absent is not zero. AuditRecord.tokens is absent on records written before the field existed, and its own doc comment forbids defaulting it to 0 — "a reader that defaults a missing value to 0 turns 'unknown' into a claim". A zero-height bar is that claim, so an unrecorded count draws a hatched void of fixed width and the words "not recorded". note renders for every kind, not only focus: four degraded hook runs that print identically is a defect this repository has already fixed once.

7Selected-but-not-delivered — the one nobody asked forנבחר אך לא נמסר

audit_item.role distinguishes injected from spilled per item and is indexed; the schema comment says in as many words that counting spills by item "is how a user finds a budget that is too small". No screen in the spec renders it. One indexed query, one diverging bar, and the budget simulator finally has an entry point: the items on the right are the argument for the number you would drag.

Delivered grows from the reading-start edge, spilled from the centre outward. In RTL both flip together — the only two physical values CSS will not mirror here are the bar's own corner radii, and the stylesheet restates them explicitly rather than leaving it to be discovered.

RTL: what mirrors, and where

CSS box model — ribbon, heatstrip, tree rows, diverging bars, feed mirrors for free via logical properties. Zero JS.
SVG interiors — staircase, comb, pulse, ego graph CSS cannot reach inside. One X(u) projection per chart: rtl ? W - u : u, applied where coordinates are emitted, plus a anchor() helper that swaps start/end. Never a scale(-1,1) wrapper — that mirrors the glyphs too.
The density rail has no interior text, so it mirrors by docking to inset-inline-end. No coordinate work at all.
Paths, ids, globs, commands stay LTR inside the RTL page (spec §3: a path is not prose), isolated with unicode-bidi:isolate.
Keyboard tree expand/collapse follows ArrowRight/ArrowLeft in LTR and swaps in RTL — a render-layer mirror of the handler, since CSS cannot mirror a key code either.

mycontext sketch 03 · compose & copy

The composed command is an object with a lifecycle.

The UI never writes. It builds the command, shows you the exact consequence before you copy it, and then recognises the audit record it leaves behind — so copy is the middle of the interaction, not the end of it. Try the three Simulate buttons in the header.

Keyboard

One table drives both the bindings and this sheet, so the sheet cannot drift from the app. Nothing fires while a text field has focus. Arrow keys resolve against the writing direction.

There is no ⌘K omnibox: this product commits to no global search, and the loop that actually needs the keyboard is compose → copy → paste → return. n opens a composer, not a search box.

is retired. They have been rewritten that way and are no longer in question here.

- **`ADR-normative-vs-rationale-tiers`** — "the notes that tell you what to do" versus
  "the ones explaining past reasoning" is the whole normative/rationale split said without
  either word. It is the furthest any of these goes from the item's own vocabulary.
- **`REQ-plan-2-precision-injection`** — the item is three sentences of roadmap; the
  summary has to name a problem ("survive a trimmed conversation") the title only implies.
- **`LESSON-mutation-testing-proves-a-guard-works-not-that-it-sits-in`** — the title already

### 3. `RULE-quote-the-test-glob` — the script it pins has a different shape

> "The script must stay `node --test \"test/**/*.test.ts\"`."

— `.my_context.nested-44/items/rule/RULE-quote-the-test-glob.md:22`

Contradicted by `package.json:20`, where the `test` script now reads
`node --import ./test/helpers/pin-rendering.ts --test "test/**/*.test.ts"`. **The quoting the
rule exists to protect is intact** — the glob is still double-quoted — but the literal script

count matches the number of files under `test/`") is now automated as
`scripts/check-test-glob.ts`, run by `.github/workflows/ci.yml` *before* `npm test`; and the
item's `scope` still lists `.github/workflows/**`, which does exist.

### 4. `DEC-focus-discloses-and-allows-rather-than-refusing-to-hide` — the relation lists are short by three

> "blocks, unblocks, depends_on, constrains, answers, enforces, enforced_by and refines are

— `.my_context.nested-44/items/decision/DEC-focus-discloses-and-allows-rather-than-refusing-to-hide.md:32-35`

Contradicted by `RELATION_CLASSIFICATION` in `src/core/focus.ts:128`, which classifies three

fallback sentence ("A relation type outside that table counts as load-bearing") is still true
of the code (`isLoadBearing`, `focus.ts:199`), but it no longer describes what happens to
these three, which are now in the table. Everything else in the item verifies: `focus.ts:349`
writes `.my_context/state/focus.json`, and `mycontext focus --relations` prints the table
(`src/cli/commands/focus.ts:97`).
